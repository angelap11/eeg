5. SEIZURE-PREDICTION METRICS
----------------------------------------------------------------------
STATUS: IMPLEMENTED — verified to exist in code, not just planned

- Where: EEG_seizure_prediction_metrics.ipynb (self-tested on synthetic
  data), reused verbatim in EEG_logistic_loso_binary.ipynb.
- Primary (event-level), fold_seizure_event_metrics():
  - Seizure sensitivity: binary per fold, did >=1 true PREICTAL TEST
    epoch get predicted PREICTAL.
  - Time in warning: time_to_next_seizure_sec of the earliest
    correctly-alarmed epoch; NaN (never 0) if undetected.
  - False alarms/hour: consecutive positive INTERICTAL predictions
    merged into one "alarm event" before counting (so one sustained
    false alarm != many), divided by TEST-interictal hours; NaN when a
    fold has zero interictal hours.
- Secondary (epoch-level): accuracy/precision/recall/F1 with
  zero_division=np.nan (never silently 0), AUC-PR explicitly forced to
  NaN (not sklearn's degenerate 1.0) when TEST has only one class.
- Handling of zero-interictal folds: explicit NaN, verified in real
  output (overall_horizon_summary.csv, patient_horizon_summary.csv —
  CHB12 rows literally show blank/NaN for FA/hour and AUC-PR with a
  stated reason string "only one class present in y_true (AUC-PR is not
  meaningful)").
- Aggregation: event counts and interictal-hours are SUMMED across folds
  before dividing once (not averaged per-fold rates); epoch metrics
  computed on the CONCATENATION of TEST epochs across folds — both
  documented as chosen conventions, not literature-standard.
- What's still missing: no statistical significance / confidence
  intervals on any pooled metric; no ROC-AUC or calibration metrics
  (intentionally out of scope).

of the brain (say, the temporal lobe) but not others, that signal gets
blended away — every recording's ~23 channels get averaged into a single
number per feature, per epoch. Ema's requirement to keep channels
separate is not done yet anywhere in the pipeline.

STATE DEVIATION INDEX — SEPARATE AUDIT
----------------------------------------------------------------------
What exists: EEG_TCN_state_deviation_forecasting.ipynb (CHB24+CHB12, old
4-class target).

Mathematical definition (verified directly from the notebook, cell
15/16):
1. 14 qEEG features standardized: x_scaled = (x - baseline_mean) /
   baseline_std, where mean/std are fit ONLY on a TRAIN-recording
   "stable baseline" (epochs that are neither seizure-overlapping nor
   within 120s of an upcoming seizure).
2. Baseline covariance diagnostics run first (rank/condition number) — a
   plain Mahalanobis distance was NOT adopted directly because of this
   check; instead:
3. PCA is fit on the standardized baseline, retaining 99% of baseline
   variance (VARIANCE_RETAIN = 0.99).
4. Index defined as:
   eeg_state_index(epoch) = sqrt( sum_{i=1}^{k} ( pc_i(epoch) /
   sqrt(lambda_i) )^2 )
   — a PCA-whitened Euclidean distance, i.e. a Mahalanobis-equivalent
   distance from the stable baseline. 0 = exactly at baseline.
5. Sequences of 10 consecutive index values (5 min) feed a causal
   dilated TCN predicting the old 4-class target.

Is it scientifically/mathematically finalized? No — it is a working
proof-of-concept with a known, serious failure documented in the
notebook's own test evaluation: TEST ACCURACY 78.9% BUT MACRO-F1 ONLY
0.22 — the model collapses to predicting almost exclusively the majority
>120s class; all three near-term classes have 0 precision and 0 recall.
This failure is stated in the project record as a large part of the
motivation for moving to the binary reformulation.

Does it participate in the new binary LOSO experiment? NO — verified by
direct search. eeg_state_index appears in zero of
EEG_binary_preictal_labeling.ipynb, EEG_patient_normalization.ipynb,
EEG_loso_evaluation_splitting.ipynb, or EEG_logistic_loso_binary.ipynb.
The new pipeline uses the 14 raw qEEG features directly (confirmed in
the LR notebook's FEATURE_COLS), never the collapsed index. The two
lines of work (old 4-class+index vs. new binary+LOSO) are currently
COMPLETELY SEPARATE.

F. IMPORTANT RISKS
======================================================================

1. CHB12 has zero measurable false-alarm rate in every fold. Any paper
   claim about "false alarms/hour" that pools both patients is,
   numerically, almost entirely a CHB24 number. Reporting a single
   pooled FA/hour without this caveat would misrepresent the result.

2. At H=30 min, a naive majority-class classifier matches or beats the
   real model on sensitivity/FA-hour. Any headline result at H=30 needs
   AUC-PR or probability-separation cited alongside sensitivity, or it
   overstates what the model is doing.

3. Only 19 of 35 annotated seizures are usable at all, due to seizure
   clustering. This shrinks the effective sample size for event-level
   claims (seizure sensitivity is an 18-or-19-out-of-19 statistic, not
   out of 35) — should be stated plainly in any methods section.

4. Channel-averaging (row 10) may be suppressing the strongest signal.
   If seizure-related change is regionally localized, the current
   14-feature representation may be underselling every model's true
   achievable performance — worth flagging before drawing conclusions
   about model ARCHITECTURE differences (LR vs RF vs TCN), since a
   channel-blind representation caps all three similarly.

5. EEG_preprocessing.ipynb's current execution state is unverified — if
   the paper cites REST/SLEEP/CHB01 preprocessing details, that specific
   notebook should be re-run and reconciled with its saved outputs
   first.

6. Small-N generalization risk: every result so far is 2 patients. Any
   claim of "the model generalizes across subjects" is not yet
   supported — it's the correct next test (row 11), not yet done.
